# Provenance

The Model Efficiency Router originated from a user-defined workflow for conserving model credits during long-running projects:

1. Work on routine tasks with an economical default model.
2. Forecast the complexity of the next distinct task.
3. Notify the user before a stronger model becomes useful.
4. Return to the economical model when the complex phase is complete.

The scoring rubric, task-boundary method, notification format, routing safeguards, and return-to-baseline logic were developed as an original Agent Skill in July 2026.

No third-party code, prompts, scripts, or reference material are included.
